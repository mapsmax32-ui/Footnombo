# Footnombo ⚽

Android-игра о карьере футболиста.

Первая версия включает создание игрока, кастомизацию, тренировки, развитие характеристик, мораль, доверие тренера, выбор стиля матча и статистику.

GitHub Actions автоматически собирает debug APK.

Build verification for OpenGL 3D player.

Latest character customization build.
